# PiUS 기획서 — 농수산물 산지직송 멀티셀러 커머스 플랫폼 (v1 초안)

농수산물 산지직송 멀티셀러 커머스 플랫폼 기획서를 **리액트로 구동하는 문서**입니다. 홈페이지가 아니라 기획서 뷰어입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 에 정적 파일 생성 → 아무 정적 호스팅에 올려서 공유
```

## 구성

| 경로 | 내용 |
|---|---|
| `src/sections/` | 01 개요 · 02 플로우(SVG) · 05 레퍼런스 · 06 논의 안건·확인 필요·일정 |
| `src/screens/` | 화면 31개 — 각 화면의 와이어프레임 · 번호 설명 · 화면정의서가 한 객체에 들어 있음 |
| `src/doc/kit.jsx` | 공통 부품: `<Go to="s22"/>` 화면 이동 참조, `<P n={1}/>` 번호 핀, `<Prop/>` 제안 표시 |
| `src/doc/Layer.jsx` | 플로우 hover 미리보기, 클릭 상세 패널(드래그 리사이즈), 버전 바, 복사·인쇄 방지 |
| `src/assets/` | PiUS 로고 (가로형 흑·백, 세로형, 심볼 흑·백, 아웃라인) |

## 규칙

- 화면 키: 화면 번호 `2.1` → `s21`. 화면을 추가하면 `src/screens/*.jsx` 배열에 넣고, 플로우 좌표는 `src/sections/Flow.jsx`의 `NODES`에 추가.
- 요구사항 원문에 없거나 미확정인 내용은 반드시 `<Prop/>`(제안) 표시.
- 버전 추가: `src/App.jsx`의 `VERSIONS`.
